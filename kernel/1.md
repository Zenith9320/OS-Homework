❯ 为什么要make build                                                            

● 因为这个项目不是标准的 cargo build 就能编译的。看 Makefile 里实际执行的 cargo
  命令：

  cargo build \
    -Z build-std=core,alloc \
    --target targets/riscv64.json \
    --features "board_qemu nographic ..." \
    --release

  三个必须用 make 的原因：

  1. --target targets/riscv64.json — 自定义目标平台，不用这个的话会编译成 x86_64
   Linux 二进制，所有 #[cfg(riscv64)] 的代码都会被跳过，导致你刚才看到的 179
  个"找不到函数/类型"错误。
  2. -Z build-std=core,alloc — 这是 nightly-only 的
  flag，重新编译标准库适配自定义目标。不用的话链接不过。
  3. --features "board_qemu ..." — 很多内核功能是 feature-gated 的，不传 feature
   的话关键模块直接不会被编译。

  另外 build.rs 还强制要求环境变量 ARCH，这个也是 Makefile 设的。不用 make
  就得每次手动敲这串长命令。
